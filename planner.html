// HOW IT WORKS

Built with plain JavaScript.

No framework and no build step — just the browser APIs that keep the planner fast and private.

01

Add & validate

The form checks the title and due date before adding anything. Errors appear inline and focus moves to the field that needs attention.

02

Filter & sort

Show all, active or completed tasks, then sort by due date, priority or when the task was created. Counts update instantly.

03

Save locally

Each change is written to localStorage. Reload the page and the list is still there — no sign-up and no network request.
